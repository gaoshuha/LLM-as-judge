## 解释模板

- 基线交换顺序后的翻转率为 0.197。明显高于 0 表明 Judge 对呈现位置敏感；应同时结合正序与逆序准确率差异判断偏好方向。
- Reason-then-Judge 的翻转率为 0.295。若低于基线且准确率不下降，则该提示干预有效。
- Swap-then-Merge 后强回答胜率为 0.705，强制平局率为 0.197。它以更多平局换取对冲突结论的保守处理。
- 两种方法结合后的强回答胜率为 0.656，强制平局率为 0.295。应与单独干预比较，而不能只看翻转率。
- Accuracy 按全部有效判决中选择 strong 的比例计算；tie 不计正确。题面公式中的第二项应为加号，而非减号。

## 长度偏见（V3 专用）

V3 中弱回答是 V2 弱回答的注水扩写版：内容（含错误）不变，长度≥2 倍。判断长度偏见的核心对照是 V3 与 V2 的弱回答胜率之差：

- 基线弱回答（注水版）胜率为 0.107。若明显高于 V2 同一条件的弱回答胜率，说明 Judge 因冗长而高估弱回答，即存在长度偏见。
- Reason-then-Judge 的弱回答胜率为 0.123。若该干预能把胜率压回 V2 水平，说明先推理后判决有助于抵抗长度偏见。
- 也可比较 V3 与 V2 的 Accuracy 差值；Accuracy 下降越多，长度偏见越严重。
